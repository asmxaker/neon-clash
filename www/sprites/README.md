# Спрайты бойцов

Спрайтовый рендер включён для **KAI**: в `www/sprites/kai/` лежат готовые PNG-полосы. Остальные девять бойцов и босс по-прежнему рисуются процедурно.

Если PNG или отдельная анимация не загрузятся, `drawFighter()` автоматически вернётся к процедурной пиксельно-неоновой отрисовке.

## Файлы KAI

```text
www/sprites/kai/
  manifest.json
  idle.png      6 кадров
  walk.png      8 кадров
  punch.png     5 кадров
  kick.png      5 кадров
  _layout.svg   шаблон сетки
```

Анимации без отдельного файла собираются из этих полос через `start`:

| Анимация | Файл | Кадры | Start |
| --- | --- | ---: | ---: |
| `idle` | `idle.png` | 6 | 0 |
| `walk` | `walk.png` | 8 | 0 |
| `jump` | `kick.png` | 2 | 0 |
| `punch` | `punch.png` | 5 | 0 |
| `kick` | `kick.png` | 5 | 0 |
| `special` | `punch.png` | 5 | 0 |
| `block` | `punch.png` | 1 | 0 |
| `hit` | `punch.png` | 1 | 4 |
| `ko` | `kick.png` | 1 | 4 |

## Формат кадра

- PNG с прозрачным фоном.
- Один горизонтальный ряд кадров на файл.
- Кадр `256×256`.
- Персонаж смотрит **вправо**.
- Ступни на anchor `(128, 242)`.
- Одинаковый масштаб внутри полосы.
- Без теней, текста и UI.
- Шаблон сетки: [`kai/_layout.svg`](kai/_layout.svg).

## manifest.json

```json
{
  "charId": "kai",
  "frameW": 256,
  "frameH": 256,
  "anchorX": 128,
  "anchorY": 242,
  "scale": 0.96,
  "animations": {
    "idle": { "file": "idle.png", "frames": 6, "start": 0, "fps": 10, "loop": true },
    "hit":  { "file": "punch.png", "frames": 1, "start": 4, "fps": 8, "loop": false }
  }
}
```

- `frames` — сколько кадров брать из полосы.
- `start` — с какого кадра полосы начинать (по умолчанию 0).
- `fps` — скорость для `loop`-анимаций и состояний без таймингов атаки.
- `loop` — зацикливать ли анимацию.
- `scale` — общий масштаб относительно мировых координат.

## Как это работает

- `sprites.js` при старте загружает `manifest.json` и PNG включённых бойцов.
- `drawFighter()` спрашивает `getSpriteFrame(f)`.
- Кадр выбирается по `f.state` и `f.attack.kind`:
  - `idle`, `walk`, `jump`, `block`, `hit`, `ko`;
  - `attack` + `punch` → `punch`;
  - `attack` + `kick` / `airkick` → `kick`;
  - остальные атаки → `special`.
- Для атак кадр привязан к `attackT`, чтобы удар совпадал с активной фазой.
- Спрайт рисуется с anchor и зеркалится по `facing`.
- `flash` от попадания передаётся через `ctx.filter`.
- `variant === 1` (mirror) получает тёплый hue-rotate, чтобы совпадать с alt-палитрой.
- KO-кадр поворачивается вокруг ступней, как процедурный боец.
- Если кадра нет, используется процедурная отрисовка **этого состояния**.

## Как добавить другого бойца

1. Создай `www/sprites/<charId>/`.
2. Положи `manifest.json` и PNG-полосы.
3. Добавь id в `SPRITE_ENABLED` в `www/js/sprites.js`:

```js
const SPRITE_ENABLED = new Set(['kai', 'neko']);
```

4. Добавь файлы в `ASSETS` в `www/sw.js` и подними `CACHE`.
5. Проверь fallback: удали один PNG и убедись, что игра не падает.
