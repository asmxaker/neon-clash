# KAI — дизайн-бриф для спрайтов

Первый персонаж с подключённым спрайтовым листом. В игре KAI уже использует PNG из `www/sprites/kai/`, а процедурная отрисовка остаётся fallback. Этот документ описывает дизайн, палитру и раскадровку для доработки ассетов.

> Это оригинальный персонаж Neon Clash. Референсы используются только как ориентир по атмосфере, не для копирования чужих персонажей.

## 1. Роль

- **Имя:** KAI.
- **Архетип:** быстрый энергетический боец.
- **Стиль игры:** давление скоростью, рывки, вход в контакт.
- **Оружие:** плазменное копьё / энергетический клинок.
- **Особенность:** длинные энергетические «уши»-антенны, визор, короткая куртка, развевающийся шарф.
- **Спец-атака:** Spark Rush — рывок сквозь соперника.
- **Статы:** HP 92, speed 370, air 275, jump 1170, damage ×0.92.

## 2. Палитра

| Роль | HEX |

Ограничение: 6–8 цветов на кадр плюс прозрачность. Без плавных фото-градиентов.

## 3. Силуэт

- Рост примерно 220 px в кадре 256×256.
- Голова ~30 px, туловище ~60 px, ноги ~100 px.
- Худой, но спортивный: широкие плечи, узкая талия.
- Две длинные антенны-«уха» назад/вверх, слегка пружинят.
- Высокий воротник, короткая куртка, открытые предплечья с энергетическими манжетами.
- Узкие штаны, массивные ботинки.
- Шарф или энергетический хвост слева по движению.
- Копьё держится в правой руке; в idle — вертикально/на плече; в рывке — вперёд.

## 4. Технический формат

| Параметр | Значение |
| --- | --- |
| Кадр | 256×256 |

| Взгляд | вправо |
| Фон | прозрачный |
| Масштаб | одинаковый |
| Контур | 2–4 px, неон |
| Заливка | тёмная |

| Интерполяция | nearest-neighbor, без сглаживания |

## 5. Анимации

Сейчас в репозитории четыре исходные полосы; остальные состояния собираются из них через `start`/`frames` в manifest.

| Анимация | Файл | Кадры | FPS | Loop | Что происходит |
| --- | --- | ---: | ---: | --- | --- |
| `idle` | `idle.png` | 6 | 10 | да | дыхание, покачивание корпуса, антенны, свечение копья |
| `walk` | `walk.png` | 8 | 12 | да | контакт/проход, шаг, развевающийся шарф, копьё в руке |
| `punch` | `punch.png` | 5 | 18 | нет | замах → выпад → удар (3-й кадр) → возврат → стойка |
| `kick` | `kick.png` | 5 | 16 | нет | подъём колена → вынос → удар (3-й кадр) → возврат |
| `jump` | `kick.png` | 2 | 8 | нет | подъём колена в воздухе |
| `special` | `punch.png` | 5 | 14 | нет | серия удара с энергетическим всплеском |
| `block` | `punch.png` | 1 | 8 | да | стойка блока |
| `hit` | `punch.png` | 1 | 8 | нет | возврат в стойку + flash |
| `ko` | `kick.png` | 1 | 8 | нет | падение: кадр поворачивается вокруг ступней |

Файлы:

```text
www/sprites/kai/
  manifest.json
  idle.png
  walk.png
  punch.png
  kick.png
```

Игровые хитбоксы **не** привязаны к кадрам: попадание считает `Fighter.getAttackBox()` по таймингам. Но визуальный удар должен совпадать с активной фазой:

- punch: активный кадр ~3/5;
- kick: активный кадр ~3/5;
- special: всплеск на 3-м кадре.

`jump`, `special`, `block`, `hit`, `ko` можно позже заменить отдельными полосами: достаточно поменять `file`/`frames`/`start` в manifest.

## 6. Ключевые позы

### Idle

- Вес на правой ноге, левая чуть впереди.
- Корпус дышит, плечи двигаются на 1–2 px.
- Антенны качаются с задержкой.
- Копьё светится пульсом.

### Walk

- 8 кадров: 4 фазы шага + 4 зеркальные.
- Корпус слегка наклонён вперёд.
- Шарф/хвост отстаёт на 2–3 кадра.
- Рука с копьём не размахивает слишком широко.

### Punch

- Кадр 1: сжатие, локоть назад.
- Кадр 2: вынос плеча.
- Кадр 3: полное вытяжение, кулак/энергия впереди.
- Кадр 4: возврат.
- Кадр 5: стойка.

### Kick

- Кадр 1: подъём колена.
- Кадр 2: разворот бедра.
- Кадр 3: вынос голени, носок вперёд.
- Кадр 4: сгиб.
- Кадр 5: стойка.

### Special / Spark Rush

- Кадр 1: присед, копьё назад.
- Кадр 2: энергия вокруг ног.
- Кадр 3: рывок, сильный наклон.
- Кадр 4: удар копьём.
- Кадр 5: торможение.
- Кадр 6: возврат в стойку.

## 7. Правила стиля

Делать:

- тёмная заливка + яркий неоновый контур;
- читаемый силуэт на чёрном фоне;
- крупные пиксели, без сглаживания;
- одинаковые пропорции и anchor во всех кадрах;
- энергетические акценты копья и антенн;
- альтернативную палитру для mirror-боя.

Не делать:

- фон, тени, текст, UI;
- мягкие градиенты и фото-текстуры;
- разные размеры персонажа в кадрах;
- смена направления взгляда;
- лишние детали, которые исчезают при уменьшении до телефона.

## 8. Как проверить

1. Положить/обновить PNG и manifest в `www/sprites/kai/`.
2. Убедиться, что `kai` есть в `SPRITE_ENABLED` (`www/js/sprites.js`).
3. Поднять `CACHE` в `www/sw.js` и запустить `npm run dev` на новом порту.
4. Проверить:
   - idle/walk без дёрганья;
   - удар/пинок попадают визуально в активную фазу;
   - при `facing = -1` спрайт зеркалится;
   - HUD-портрет и карточка выбора не ломаются;
   - Network guest использует те же кадры.
5. `npm run apk` и проверить на Android.

Если какой-то анимации нет, `sprites.js` оставит процедурную отрисовку для этого состояния. Полный список — в [`www/sprites/README.md`](../www/sprites/README.md).
